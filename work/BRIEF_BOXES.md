# Brief — transcribe and translate the 专栏 (policy boxes) and 图 (figures)

The source article renders its 专栏/图 as JPEG images. We are re-typesetting them as **real text**, bilingual, so the PDF is searchable and looks like the rest of the document.

Working directory: `/home/agheieff/fyplan`

## Your assignment
See `/home/agheieff/fyplan/work/boxes/ASSIGN_A.json` (or `ASSIGN_B.json`). It lists, for each image: the index, the path (`img/NN.jpg`), and the document context (Part / Chapter) it belongs to.

## Method, per image
1. Open the image with the **read_image** tool and read it carefully, top to bottom.
2. Identify the title bar. It reads either `专栏 N  <title>` (a policy box) or `图 N  <caption>` (a map/figure).
3. Transcribe the Chinese **exactly as printed** — do not paraphrase, do not modernise, do not fix wording, keep the original punctuation（，。；：、“”《》）and spacing conventions. Keep the leading zero in item numbers (`01`, `02`, …).
4. Translate into English following `/home/agheieff/fyplan/work/GLOSSARY.md` (mandatory terms + register).
5. Write one JSON file per image: `work/boxes/box-NN.json` where NN is the image index (zero-padded), e.g. `work/boxes/box-03.json` for `img/03.jpg`.

## Output schema

```json
{
  "img": 3,
  "file": "img/03.jpg",
  "kind": "box",
  "number": 3,
  "title_zh": "新产业新赛道培育发展",
  "title_en": "Cultivation and Development of New Industries and New Tracks",
  "blocks": [
    {"t": "head", "num": "01", "zh": "集成电路", "en": "Integrated Circuits"},
    {"t": "p", "zh": "做精做细成熟制程，提高先进制程制造能力……", "en": "Refine mature-process nodes ..."},
    {"t": "subhead", "zh": "……", "en": "……"},
    {"t": "bullet", "zh": "……", "en": "……"},
    {"t": "table", "cols": [{"zh": "类别", "en": "Category"}, {"zh": "指标", "en": "Indicator"}],
     "rows": [[{"zh": "经济发展", "en": "Economic development"}, {"zh": "1.国内生产总值（GDP）增长（%）", "en": "1. GDP growth (%)"}]],
     "notes": [{"zh": "注：……", "en": "Note: ..."}]}
  ]
}
```

Field rules:
- `kind`: `"box"` for 专栏, `"figure"` for 图, `"table"` if the whole graphic is a table (专栏1).
- `number`: the integer after 专栏 / 图. `null` if you genuinely cannot determine it.
- `title_zh` / `title_en`: the title **without** the `专栏 N` / `图 N` prefix — the prefix is generated by the typesetter.
- `blocks` is an ordered list. Use exactly these `t` values:
  - `head` — a numbered item heading (`01`, `02`, …). `num` is the printed number string, `zh`/`en` the heading text.
  - `p` — a paragraph. If it continues the numbered item above it, just emit `p` blocks in order.
  - `subhead` — an unnumbered sub-grouping line inside the box.
  - `bullet` — a numbered/bulleted sub-line inside an item (e.g. `1. …`, `（1）…`); keep the printed marker at the start of `zh` and `en`.
  - `table` — a real table; `cols` defines width, every row must have the same number of cells as `cols`, `notes` is optional and rendered under the table.
- For a **table** with merged cells (专栏1's 类别 column merges over several rows): **repeat the merged value in every row.** The typesetter merges identical consecutive cells automatically. Use `""` only where the cell is genuinely empty.
- For `kind: "figure"` (maps such as 图1 / 图2 / 图3): set `title_zh`/`title_en` to the caption, `blocks` to the legend entries and footnotes only (`subhead`/`p`), and leave `number` as the figure number. **Do not** attempt to transcribe the place names or line labels printed on the map itself — the map artwork is inserted as an image.
- Text that appears in a coloured band at the very bottom of a figure (a caption) goes in `title_zh`/`title_en`.

## Quality bar
- Every visible Chinese character in the graphic must appear in your `zh` fields. Missing a row is worse than an ugly translation.
- Numbers must match the image exactly (including `—` for "no target").
- No LaTeX, no Markdown, plain UTF-8 strings. `& % $ # _ { } ~ ^` must not be escaped.
- Self-check each file parses: `python3 -c "import json;json.load(open('work/boxes/box-03.json'))"`.
